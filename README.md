# MM Dairies — Store Admin Panel

Independent React admin dashboard for store operators. Shares the same design system and UX patterns as the Super Admin Panel, but is a **separate project** with no shared runtime dependencies.

## Modules

- Dashboard
- Live Orders / Running Orders / Completed Orders
- Products (select from master catalog — no master product creation)
- Customers + Resolve Query chat
- Reports

## Getting started

```bash
npm install
npm run dev
```

Demo login: any username (min 3 chars) + password (min 4 chars).

## Stack

- React 19 + Vite + TypeScript
- Tailwind CSS 4
- React Router
- Recharts
- Framer Motion
- Lucide icons
